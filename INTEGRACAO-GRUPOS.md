## Publicar no GitHub
O ZIP contém o repositório completo. Extraia e envie **o conteúdo da pasta raiz do projeto** ao repositório, preservando as pastas `public` e `data`. Não mova os arquivos HTML para a raiz.

Para atualizar uma branch que já contém o commit-base, basta adicionar/atualizar `public/projetos.html`, `public/style.css`, a pasta `public/grupos/grupo4/` e opcionalmente este README.
