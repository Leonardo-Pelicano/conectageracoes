# ConectaGerações — integração dos projetos dos grupos

## Página de grupos
A página `grupos.html` reúne os oito projetos:
- Grupos 1, 2, 3, 5, 6 e 8 abrem os endereços publicados em nova aba.
- Grupo 4 abre localmente em `grupos/grupo4/index.html`.
- Grupo 7 está identificado como "Em breve!" e não possui link.

## Retorno ao ConectaGerações
Todas as páginas do Grupo 4 exibem no topo a opção "Voltar aos grupos", que leva a `../../grupos.html`. Assim, o visitante retorna à página de integração, e não à home por engano.

## Observação sobre o material do Grupo 4
O arquivo recebido continha cinco páginas HTML, mas não continha as pastas CSS, JavaScript e imagens referenciadas pelo HTML original. Foram adicionados arquivos de suporte locais para evitar páginas sem estilo ou funcionalidades quebradas. As imagens ausentes foram substituídas por uma ilustração SVG genérica. O quiz tem uma implementação funcional de demonstração; os textos e perguntas devem ser revisados com o grupo responsável caso exista uma versão original desses recursos.
